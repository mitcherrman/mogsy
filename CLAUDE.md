# Mogzy frontend — Claude Code rules

Read [AGENTS.md](AGENTS.md) before running tools or tests. Its local-browser safety rules apply to every task, every subagent, and every worktree. **Never run automated local Microsoft Edge/Google Chrome or visible browser sessions.** Use GitHub Actions for browser acceptance; request approval for any bundled headless Chromium locally. Respect branch isolation, test evidence and no unapproved deploy.

**Resource and verification policy (also in AGENTS.md):** declare a verification level (L1 isolated / L2 behavioral / L3 critical-or-release) and the narrowest test plan that proves the change. Targeted tests (up to 8 named test files) run directly, also while League of Legends and Firefox are open: `vitest.config.ts` gives them 1 worker, a heap cap and below-normal priority, and nothing blocks them. Broad jobs (folders, full suite, build, project-wide tsc, Playwright) run only when the level requires it, once, through `tools/dev-guard/mogzy-guard.cmd run --class <vitest|build|e2e> -- <cmd>`, which serializes them but never refuses because of League, Firefox or RAM. No reruns of green, unchanged tests; no local screenshots or baseline comparisons; browser and exhaustive suites go to GitHub Actions. A gate that could not run is reported as NOT RUN, never as a pass. Matrix: `docs/dev/TESTING_MATRIX.md`.
